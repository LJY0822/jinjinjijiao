# 金金计较 · 蟹小钳

以确定性账本为财务事实基础，用 AI 帮助用户记录消费、审视购买理由并持续执行预算的个人财务助手。

项目阶段：本地网页 MVP / 课程汇报演示。此仓库用于公开项目定位和开发进度，当前未公开完整源码、人设提示词与财务记忆协议。

## 产品流程

记录或讨论消费 → 对照本周流水与预算 → 生成交易草稿或消费建议 → 用户核对并选择入账 → 预算同步更新。

AI 提供建议，用户保留最终决定权；只有确认后的交易才进入账本。

## 已实现

- 手机浏览器适配的总览、流水、预算计划页面。
- 手动记录收入与支出、分类统计、月份筛选、搜索、CSV 导入导出。
- 聊天与记账共用入口；读取本周流水，生成可修改、放弃或确认的交易草稿。
- 严肃监督风格的蟹小钳、吉祥物点击反馈与表情互动。
- 多轮聊天、每80条用户/助手消息的记忆总结，支持手动总结、查看和编辑。
- 模型调用通过本地服务完成，API 凭据不放在前端。

功能实现不等于所有场景均验证通过；最新模型配置尚未验证可用性。当前无账户登录、跨设备同步、银行连接或线上生产部署。
